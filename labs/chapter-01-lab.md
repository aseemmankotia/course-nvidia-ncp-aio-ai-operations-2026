# Chapter 1 Lab: Base Command Manager: Installation and Cluster Initialization

**Estimated time:** 35 minutes

## Exercise

Install BCM on a three-node cluster, provision two compute nodes, create a user account with operator role, and verify Base View shows live GPU metrics

## Key takeaway

BCM is the single control plane for NVIDIA cluster lifecycle—provisioning, monitoring, and user management—and the exam's largest domain at 31%.
