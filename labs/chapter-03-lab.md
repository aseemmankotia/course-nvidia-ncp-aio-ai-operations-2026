# Chapter 3 Lab: Advanced BCM Operations: Firmware, Networking, and Troubleshooting

**Estimated time:** 30 minutes

## Exercise

Use BCM to update GPU firmware on all A100 nodes, configure InfiniBand fabric settings, install DOCA Services on a BlueField-3 DPU, and troubleshoot a node stuck in 'provisioning failed' state by checking cmsh logs

## Key takeaway

BCM handles firmware, DPU networking, and cluster health monitoring—always check 'cmsh show health' and reboot after firmware updates.
